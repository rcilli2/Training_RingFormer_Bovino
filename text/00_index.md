% BOVINO Full Reproduction

This package reproduces the MiniTransformer experiment with MC Dropout uncertainty estimation.

1. Install `uv`.
1. Run `training/start.bat`.
1. Open `notebooks/00_full_reproduction.ipynb` in JupyterLab.

The default environment uses CPU PyTorch. Use `run_smoke_test.bat` before starting the complete LOBO or LOCO workflows.
